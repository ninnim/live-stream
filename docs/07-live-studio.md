# 07 — Live Studio

## Phase 1 studio

- Stream preview
- Camera selector
- Microphone selector
- Start/stop controls
- Health indicators
- Session timer
- Basic chat panel
- Recording state

## Professional studio later

- Scenes
- Source ordering
- Multiple cameras
- Screen share
- Image/video overlays
- Lower thirds
- Branding
- Audio mixer
- Guest feeds
- Hotkeys
- Remote control
- Preview/program concepts

## Layout principles

Keep the central media preview dominant. Put high-frequency operational controls within one interaction of the preview. Secondary configuration should open in side panels rather than replace the main control room.

## Realtime events

Studio consumes server events such as:

- session status changed
- ingest connected
- ingest disconnected
- destination status changed
- bitrate changed
- viewer count changed
- recording status changed
- moderation event

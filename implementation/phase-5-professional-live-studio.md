# Phase 5 — Professional Live Studio

## Objective

Turn the control room into a serious production environment that reduces the need for OBS.

## Scope

- Scenes.
- Multiple sources.
- Camera switching.
- Screen share.
- Overlays.
- Lower thirds.
- Branding.
- Audio mixer.
- Remote guests.
- Hotkeys.
- Preview/program workflow.

## Acceptance criteria

A professional user can produce a multi-source show natively from the platform for the primary supported workflows.

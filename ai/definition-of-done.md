# Definition of Done

A phase feature is Done only when all applicable items are satisfied:

- Product behavior matches the phase document.
- Authorization is enforced.
- Validation is present.
- Database migrations exist and apply cleanly.
- API contracts are documented.
- Realtime events are documented and tested.
- Core happy path works.
- Important failure/retry paths work.
- Logs/metrics are present for operationally important actions.
- No secrets are exposed.
- Existing tests still pass.
- New tests cover new business logic.
- Frontend handles loading, success, reconnecting, and failure states.
- Documentation reflects the implemented behavior.
- Known limitations are explicitly reported.
